# SnowBound

A stylised-realistic ski / snowboard resort game made in Unity.

- **Unity version:** 6000.0.x (Unity 6)
- **Render pipeline:** URP (Universal Render Pipeline)

## Milestone 1 — playable vertical slice

Target gameplay loop:

`Lodge → walk to chairlift → board → ride up → exit at top → ski or snowboard down → reach the bottom → return to lodge`

Everything in milestone 1 is built from procedural geometry and Unity
primitives. No external 3D assets. Placeholder objects are generated by
components so they can be swapped for real models later without touching
gameplay code.

## Folder layout

```
Assets/
  Scenes/                 the game scene(s)
  Scripts/
    Core/                 shared helpers (procedural meshes, materials)
    Player/               character, movement modes, camera
    Mountain/             terrain generation and scene dressing
    Lifts/                chairlift
  Prefabs/
  Materials/
  Models/
  Audio/
  UI/
```

## Build order

1. **Mountain** — terrain mesh, pine trees, rocks, piste markers. *(done)*
2. Lodge and base area.
3. Player: walking, gravity, jumping, third-person camera.
4. Skiing and snowboarding movement modes.
5. Snow spray and tracks.
6. Chairlift.
7. Loop glue: gear swap at the lodge, start/finish areas.

## Notes

- `MountainGenerator` is the single source of truth for ground height.
  Other systems call `SampleHeight(x, z)`, `PisteCenterX(z)` and
  `PistePoint(z)` instead of guessing or raycasting.
- Generated geometry uses `HideFlags.DontSave`, so the scene file stays
  small. The mountain rebuilds automatically on Play; in the editor use the
  component's **Build Now** context-menu item to preview it.
